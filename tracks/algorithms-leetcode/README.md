# Algorithms & LeetCode

This track is for Java-based algorithm practice and interview preparation.

## Focus Areas

- Arrays, strings, hash tables.
- Binary search and two pointers.
- Stack, queue, heap, linked list.
- Tree, graph, DFS, BFS.
- Dynamic programming.
- Greedy algorithms and interval problems.

## Practice Style

For each important problem, keep notes in this structure:

```text
problem-id-title/
├── README.md        # idea, mistakes, complexity
└── Solution.java    # clean implementation
```

## Weekly Goal

- Keep daily practice small but consistent.
- Summarize patterns instead of only collecting accepted code.
- Revisit wrong problems after 2 days and 1 week.
