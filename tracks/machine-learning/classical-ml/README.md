# Classical Machine Learning

This folder contains existing classical machine learning course records and implementation exercises.

## Folders

| Folder | Content |
| --- | --- |
| `Bayes/` | Bayesian classification notes and notebook |
| `KNN/` | KNN implementation, KD-tree, MNIST notebook and data |
| `Version1/` | Main collection of classical ML implementations and datasets |

## Topics Covered

- KNN and distance metrics.
- Naive Bayes and probabilistic models.
- Linear regression and SGD.
- Logistic regression and evaluation metrics.
- Matrix factorization and factorization machines.
- PCA and dimensionality reduction.
- Decision trees and ensemble learning.
- K-means clustering.
- SVM and kernel methods.
- MLP basics.
- HMM and graphical-model experiments.

## Note

The original directory structure is preserved as much as possible to avoid breaking old scripts. Some scripts may assume they are executed from their own folder.
