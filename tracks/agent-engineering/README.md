# Agent Engineering

This track records my learning path for LLM application engineering and agent systems.

## Learning Order

1. LangChain basics: models, prompts, output parsing, chains, tools, memory.
2. RAG: document loading, splitting, embeddings, vector stores, retrieval, evaluation.
3. Agent patterns: ReAct, tool use, planning, execution traces, failure analysis.
4. LangGraph: stateful workflows, long-running agents, persistence, human-in-the-loop.
5. MCP: resources, prompts, tools, local servers, integration with agent workflows.
